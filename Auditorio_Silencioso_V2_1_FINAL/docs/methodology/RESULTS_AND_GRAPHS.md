# Representação dos resultados

Após cada execução, o sistema registra:
1. Ground Truth independente;
2. evidências observadas;
3. detecção do motor;
4. ações de resposta;
5. tempos;
6. efeitos sobre hosts;
7. métricas.

Os gráficos não substituem os dados. Eles são uma representação visual dos dados registrados.

Gráficos previstos:
- Taxa de detecção — CTI × SBD;
- Cobertura — CTI × SBD;
- TTD — CTI × SBD;
- TTC — CTI × SBD;
- hosts afetados/preservados, quando a série agregada estiver disponível.

Para múltiplas execuções, os valores agregados serão calculados a partir dos resultados individuais.
